# Inspection 티칭

위치·조명 티칭과 저장 이미지의 검사 설정을 별도 메뉴로 구분한다.
볼트·Data Matrix 포인트마다 티칭 영상 한 장을 저장한다.

## 위치 티칭 — Teaching → Inspection Gantry

1. Heat Sink 1 또는 2를 선택한다. 볼트는 Add Bolt로 추가하고, Data Matrix는 해당 티칭 항목을 선택한다.
2. 포인트 선택 시 저장된 조명값이 Live 조명값에 표시된다. 밝기를 조절하고 Live로 보면서 조그로 대상을 가운데 십자선에 맞춘다.
3. 축을 멈추고 Save X/Y + Image을 누른다. 선택 포인트의 촬영 XY와 기준 영상을 함께 저장한다.
4. 같은 포인트를 다시 기록하면 이미지와 좌표를 교체하며 기존 ROI는 유지한다. Live는 계속 표시한다.
5. 이미 기록한 포인트에서 Update Image + Light하면 좌표를 유지하고 기준 영상과 조명값을 저장한다. 포인트를 새로 추가하지 않는다.

조명은 Data Matrix 1/2와 각 볼트별로 0–255를 저장한다. 포인트 조명값이 없으면 레시피 기본값을 사용한다.
Live 조명값은 ViewModel의 임시 값이며 Save X/Y + Image 또는 Update Image + Light으로 촬영·저장할 때 선택 포인트에 반영한다.

이 화면은 수동 모드의 위치 티칭 전용이다. ROI·판독 설정·저장 영상 재검사는 Inspection Setup 메뉴에서 한다.
좌표 기록은 Save X/Y + Image만 수행한다. Save, 포인트 선택, ROI 편집으로 좌표를 바꾸지 않는다.

## 검사 설정 — Inspection Setup

설비 운전 여부와 무관하게 사용할 수 있는 저장 이미지 편집 화면이다. 카메라·축·조명 장치를 직접 호출하지 않는다.
Show Reference Image는 선택 포인트에 저장된 기준 영상을 다시 표시한다. 새 영상을 등록하는 버튼이 아니다.

1. 레시피를 선택하고 Load(불러오기)를 누른다. 설비의 활성 레시피 선택은 바뀌지 않는다.
2. 왼쪽에서 PCB별 Data Matrix 또는 볼트를 선택한다. DB에 저장된 기준 영상과 ROI가 표시된다.
3. 영상에서 드래그해 중앙 정사각형 ROI의 크기를 조절한다. 기존 비중앙 ROI는 선택만으로 바꾸지 않는다.
4. 볼트는 Threshold와 Minimum bright (%), 필요하면 체결 회전수 상·하한을 조정한다. Data Matrix는 판독 옵션, 최소·최대 임계값, 증가폭과 점 확장 반경을 조정한다.
5. Inspect This Image로 화면에 불러온 영상을 다시 판정한다. 이 결과는 생산 결과에 기록하지 않는다.
6. Save Settings(설정 저장)로 편집한 검사 설정을 DB에 보관한다. 영상 위의 [편집 레시피]가 실제 저장 대상이며, 레시피 목록에서 이름만 선택해도 대상이 바뀌지는 않는다.

Data Matrix는 확장 검색·반전 검색·회전 검색·순수 바코드 옵션과 임계값 탐색을 사용한다.
최소~최대 임계값을 증가폭만큼 바꾸며 판독하고, 각 값에서 일반 판독 실패 시 점 확장 후 다시 판독한다.
점 확장 반경 0은 확장 끔이다. 이전 단일 BinaryThreshold 설정은 사용하지 않는다.
볼트는 임계값 이상인 픽셀의 비율이 Minimum bright 이상이면 OK다.
자세한 계산은 [밝은 면적 비율 검사](../Stations/IBTM.Inspection/README.md)를 참고한다.

## 저장과 적용 시점

현재 운전 레시피를 불러오면 화면과 자동 검사가 같은 레시피 객체를 사용한다.
ROI·판정값·판독 옵션·체결 회전수 기준을 바꾸면 현재 메모리에 즉시 반영되며, Save를 기다리지 않는다.
화면 상단에도 즉시 적용과 저장 필요 여부를 안내한다. Save는 변경값을 DB에 보관해 재실행 후에도 유지하는 동작이다. 저장 후 입력값이나 판독 옵션을 다시 바꾸면 저장 완료 안내를 [설정 변경 · 미저장]으로 바꾼다. 이미지를 불러온 상태에서 정상 입력값이 반영되면 이전 검사·저장 오류 안내도 지운다. 이미지 읽기 실패 안내는 설정을 바꿔도 유지한다.
자동 검사는 설정을 읽는 시점의 값을 사용한다. 이미 진행 중인 Data Matrix 임계값 탐색은 그 탐색을 시작할 때 읽은 옵션으로 끝낸다.

다른 레시피를 불러오면 별도 객체를 편집한다. 그 레시피를 저장해도 현재 운전 레시피에는 적용되지 않는다.
저장 대상은 ROI, 볼트 판정값, 체결 회전수 상·하한, Data Matrix 옵션이다.
저장 직전의 DB 레시피에 이 항목만 합치므로 Gantry 티칭의 좌표·헤드 지정·기준 이미지·조명값과 다른 유닛 설정을 덮어쓰지 않는다.
다른 레시피를 편집·저장해도 현재 운전 레시피는 바뀌지 않는다.

## 저장된 생산 결과 이미지 불러오기

상단의 **검사 설정 / 이력 재검사** 탭으로 작업을 구분한다. 두 탭은 불러온 레시피의 검사 설정을 공유한다.
이력 재검사 탭을 처음 열면 설정된 월별 DB 저장 폴더에서 최근 PCB 목록을 읽는다.
생산일, 바코드·PCB 번호·레시피 검색어, 검사 판정(전체/OK/NG/대기)으로 불러온 목록을 좁힌다.
검색 범위는 현재 불러온 이력이다. [더 보기]로 이전 결과를 추가하고, [새로고침]으로 최근 이력을 다시 읽는다. 새 목록과 검색 조건에 같은 PCB가 남아 있으면 선택한 PCB와 이미지도 복원한다.

PCB를 선택하면 이미지 목록을 자동으로 읽고 첫 이미지를 표시한다. 다른 이미지는 목록에서 선택하면 바로 표시한다.
별도의 Load PCB Images / Load for Reinspection 버튼은 사용하지 않는다.
같은 레시피에서 PCB·볼트 GUID가 일치하고 기준 영상과 해상도가 같을 때 재검사와 ROI 편집이 가능하다.
레시피·검사점·해상도가 다르면 저장 원본은 조회할 수 있고, 재검사는 막으며 이유를 표시한다. 다른 레시피의 이력은 저장된 볼트 순번으로 표시하고, 같은 레시피를 불러오면 해당 볼트 이름으로 갱신한다.
이미지가 없거나 읽기에 실패하면 이전 PCB의 이미지와 판정을 지운다. 검사 설정 탭으로 이동하면 진행 중인 이력 이미지 읽기를 취소하고 이력 안내를 지운다. 이력 탭으로 돌아오면 선택한 PCB의 읽기를 재개한다.

화면에는 당시 저장된 판정과 재검사 판정을 구분해 표시한다. 검사 설정 입력 오류가 있으면 재검사 판정 대신 입력 확인 안내를 표시하고, 값을 바로잡으면 현재 설정의 판정 표시로 돌아온다. 이미지 읽기 실패 시 판정 표시는 중립색 —로 표시하며, 재검사 불가 사유는 이미지 위에 유지한다. 이미지가 없는 PCB는 이미지 목록 중앙에 안내해 설정 저장 완료 메시지와 구분한다.
재검사하거나 설정을 저장해도 생산 DB의 결과·검사 이미지와 레시피 기준 이미지는 교체하지 않는다.
검사 설정 탭으로 돌아가면 선택 포인트의 기준 영상을 표시한다.

## 이미지 표시

십자선·ROI 테두리·이진화 오버레이는 화면 표시이며 원본 PNG 픽셀에 합성하지 않는다.
Live는 위치 티칭에서만 사용하며 저장 이미지 편집 화면과 공유하지 않는다.
