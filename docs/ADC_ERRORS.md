# ADC 오류 코드와 운전자 조치

화면: **ADC Protocol → 오류 코드 / 조치**. 알람에는 포트/Slave, 코드(10진수·16진수), 설명, READY/RUN 상태가 표시된다. 생산 결과 상세의 ERROR CODE에도 설명 툴팁이 있다.

## 2026-09-21 15:29:34 응답

`01 04 0E 0001 0000 0000 0000 0000 007D 0000 3FBE`

3303부터 7개 레지스터를 읽은 응답이다. Preset=1, READY=0, RUN=0, Alarm=125(0x007D), Direction=0이다.
체결을 위한 프리셋 선택 전 현재 알람 검사에서 정지했다. 이 응답 시점의 모터는 정지 상태이고 컨트롤러는 준비되지 않았다.

**125는 아래 공개 ADC 오류표에 없다.** AL-25나 다른 제조사의 125로 바꾸어 해석하지 않는다. 정확한 원인은 설치된 컨트롤러 모델·펌웨어의 오류표로 확인해야 한다.

## 운전 처리

- 체결 결과의 NG/오류는 해당 볼트에 기록한다. 결과 대기 타임아웃도 STOP 완료 후 NG로 기록한다.
- ADC STOP은 명령 전송 후 실제 RUN=OFF를 확인한다. 정지 확인 실패는 설비 알람이다.
- 다음 START에는 현재 Alarm=0, READY=ON, RUN=OFF가 필요하다. 이전 결과가 NG인지와 현재 컨트롤러가 다시 운전 가능한지는 별개다.
- 이 목록 추가로 자동 리셋, 자동 재시도, 알람 무시 처리를 추가하지 않았다. 공정 오류 분류 자체가 계속 운전 허가는 아니다.
- IO 연결의 단일 Alarm 입력으로는 세부 숫자 코드를 알 수 없다. 세부 코드는 ADC 통신값 또는 컨트롤러 표시로 확인한다.

## 통신 예외 코드

아래 코드는 컨트롤러 운전 알람과 별개인 **Modbus 요청 거부 응답**이다. 예를 들어 `0186030261`의 `0x03`은 운전 알람 3이 아니다.

| 응답 코드 | 의미 |
| --- | --- |
| 0x01 | 지원하지 않는 기능 |
| 0x02 | 잘못된 레지스터 주소 |
| 0x03 | 허용하지 않는 데이터 길이 |
| 0x07 | 요청 CRC 오류 |
| 0x0C | 허용 바이트 수 초과 |
| 0x0E | 값 범위 오류 |
