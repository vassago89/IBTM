# 데이터 매트릭스와 사진

## 자동 동작

각 PCB의 데이터 매트릭스를 읽은 뒤, 등록된 볼트 위치마다 이동해 사진을 촬영한다.
볼트 사진은 저장·표시만 하며 볼트 유무나 밝기 비율로 OK/NG를 판정하지 않는다.
체결·회전수 판정과 데이터 매트릭스 NG 제외 옵션은 유지한다.

## 티칭과 검사 화면

티칭 화면에서 볼트를 추가하면 검사 XY와 사진을 등록한다. 기존 포인트의 이미지 갱신은 좌표를 바꾸지 않는다.
촬영 조명은 데이터 매트릭스와 볼트별로 저장하며 개별 값이 없으면 레시피 기본값을 사용한다.

검사 화면은 메인창에서 선택한 레시피를 사용한다. 카메라나 축을 움직이지 않는다.

- 데이터 매트릭스: ROI 편집, 판독 옵션, 이진화 미리보기와 재판독
- 볼트: 원본 사진 표시와 체결 회전수 상·하한 설정

데이터 매트릭스는 최소~최대 임계값을 지정 증가폭으로 탐색한다.
각 임계값에서 일반 판독 후 필요하면 검은 점 확장을 적용해 다시 읽고, 처음 성공하면 끝낸다.
화면에는 성공한 시도 또는 마지막 시도의 이진화 영상과 판독 결과를 표시한다.
설정 저장은 데이터 매트릭스 설정·ROI와 회전수 기준만 갱신한다. 위치·사진·조명값은 덮어쓰지 않는다.

## 결과 사진

결과 탭에서 생산일과 바코드로 PCB를 찾고 사진을 선택한다.
볼트 사진은 원본만 표시하며 판정·ROI·이진화 표시가 없다.
데이터 매트릭스 사진은 같은 레시피의 기준 이미지와 크기가 맞으면 검사 화면에서 재판독할 수 있다.
재판독하거나 설정을 저장해도 생산 결과와 저장 사진은 바뀌지 않는다.
십자선·ROI·이진화 미리보기는 표시용이며 원본 PNG에 합성하지 않는다.

## 히트싱크 원형 구멍 등록

1. 설정 → 카메라 조명에서 촬영면 기준 해상도(mm/pixel)를 입력한다. 영상 오른쪽은 장비 X+, 아래쪽은 Y− 방향이다.
2. 기준 제품에서 티칭 → 검사 → PCB 선택 → 피듀셜 1을 선택한다. 구멍이 보이도록 이동하고 라이브를 켠다.
3. 구멍 하나의 테두리 전체를 포함하도록 사각형을 그린 뒤 등록·저장한다. 현재 카메라 XY·윤곽·해상도·조명을 레시피에 저장한다. 실패하면 저장 필요 안내가 남으며 상단 저장으로 다시 저장할 수 있다.
4. 촬영 사진의 초록색 원과 중심을 확인한다. 카메라 라이브는 계속 켜져 있으며, 라이브 보기를 누르면 현재 영상으로 돌아간다. 떨어진 다른 구멍을 피듀셜 2로 등록한다. 두 구멍의 등록 상태는 함께 표시한다. 찾기 확인은 현재 위치에서 검출만 하며 등록값을 바꾸지 않는다.
5. 피듀셜 보정을 켜고 레시피를 저장한다. 두 PCB는 별도로 등록한다. 기존 레시피에서는 기본 OFF다.

영역을 다시 그리면 기존 윤곽을 지우므로 다시 등록한다. 피듀셜 XY는 등록·저장에서 함께 기록한다.
탐색 여유는 등록 영역을 사방으로 넓히는 픽셀 수다. 영역 안에 비슷한 구멍이 둘 이상 들어오면 찾기 실패로 표시한다.
자동 검사 중 미검출·복수 후보·두 마크 위치 중복은 실패 원인을 결과에 남기고 해당 PCB의 사진·기준면·볼트 높이를 티칭 좌표 그대로 진행한다. 이전 보정값은 재사용하지 않는다.
설정 → 카메라 조명의 피듀셜 실패 NG 제외가 OFF면 검사 완료 후 최종 NG에 반영하고, ON이면 피듀셜 실패만 최종 판정에서 제외한다. 데이터 매트릭스·높이·체결 판정은 그대로 적용한다.
결과 창의 검사 이미지 위에서 보정 적용 여부와 실패 원인, 당시 NG 제외 여부를 확인한다. 탭을 바꿔도 표시된다.
미등록·영상 크기 불일치 등 설정 오류와 모션·카메라·통신 오류는 계속 알람으로 정지한다.
형상 오차는 낮을수록 비슷한 모양이며 합격률(%)이 아니다. 크기 허용 오차는 면적으로 환산한 길이 비율이다.
해상도는 실제 촬영면 기준값을 입력하며 임의 기본값을 적용하지 않는다.
원본 사진에는 ROI나 십자선을 합성하지 않는다.

## 카메라 해상도

해상도 입력값은 영상 1픽셀에 해당하는 실제 길이(mm)다. 예를 들어 0.01이면 영상의 100픽셀이 1mm다.
X·Y에 같은 해상도를 적용하고 영상 중심과 검출 중심의 차이를 장비 좌표로 변환한다.
X는 카메라 위치에 더하고 Y는 뺀다. 두 PCB에 공통인 장비 설정이며 소수점 입력을 지원한다.
렌즈 배율이나 영상 크기 조정으로 픽셀당 길이가 달라지면 해상도를 다시 설정한다.
각 PCB의 두 피듀셜을 이용한 위치·회전 보정은 매 검사마다 수행하며 저장된 티칭 좌표를 바꾸지 않는다.
